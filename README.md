# Yarukoto

個人用タスク管理デスクトップアプリ。Next.js + SQLite + Tauri v2 によるローカル完結型。

現在の開発版: **v2.0.0-preview.1**。仕事の記録・具体化・着手・中断後の再開をつなぐ画面を追加しています。公開リリース前の検証版です。

## 特徴

- **ローカル完結**: データはすべてローカルのSQLiteに保存。クラウド不要、アカウント不要
- **いまの仕事**: 背景を含めてそのまま記録。最近開いた仕事や着手中の仕事へ、作業メモと一緒に戻れる
- **仕事の内容**: 原文を保持し、作業メモ・出どころ・次に進める子タスク・待ち条件と確認日を同じ場所で管理
- **期限の確認**: 本当の期限、実行予定、確認日は別々に管理。期限超過・近い期限・確認日を一覧フィルタに関係なく確認
- **プロジェクト**: 名前・色に加えて目指す成果と全体の期限を管理
- **今日やるタスク**: ルーティン・ピック済み・期限日タスクをまとめて表示
- **ルーティン管理**: 日次/週次/月次の繰り返しタスクを設定（祝日・休日スキップ対応）
- **階層タスク**: 子・孫タスクへ必要な部分だけ展開。循環を防ぎ、未完了の子孫をアーカイブで隠さない
- **ドラッグ&ドロップ**: タスクの並び替え・親子関係の変更をDnDで操作
- **ダッシュボード**: 完了率・7日間チャート・ステータス分布を可視化
- **アーカイブ**: 完了済みタスクの手動/自動アーカイブ
- **CSV エクスポート/インポート**: BOM付きUTF-8。改行・引用符を含む原文やメモ、作業コンテキストと階層に対応

## v2での使い方

1. 「いまの仕事」に、やることや懸念を背景と一緒に書いて記録します。改行はEnter、記録はCtrl+Enterです。プロジェクトや細かな属性は任意です。
2. 仕事を開くと、最初の記録と作業メモを読めます。進め方が見えた部分だけを子タスクにし、既存の子・孫タスクから「次に進める作業」を選べます。
3. 着手・完了は仕事の内容から操作できます。中断時には同じ作業メモへ手がかりを残し、「保存して中断」で閉じます。中断用の新しいステータスはありません。
4. 再開時は「続きから」、全体確認は「プロジェクト」へ。「すべてのタスク」「今日」のフィルタ・並べ替え・日付操作や、ルーティン・タグ・重要度・緊急度・見積時間も引き続き利用できます。

入力中の記録はこの端末のWebViewのローカル下書きとして保持します。保存済みの仕事はSQLiteに保存します。AIとの会話や外部サービスは不要です。祝日カレンダーの取得には従来どおり公開データへの通信を使います。

### 既存データ

v2のDB変更は列の追加です。既存のタイトル・メモ・親子関係・日付・状態を置き換えません。更新前には設定のデータ管理からバックアップを作成してください。検証用の別識別子でビルドしたアプリは、本番と別のDBを使用します。

CSVはタスクの持ち運び用です。プロジェクトの成果・全体の期限、ルーティン、設定を含めた保存にはSQLiteバックアップを使用してください。

DB復元時は、以前の下書きが別の仕事に紐づかないよう、入力中の下書きを同じ端末内に退避します。保存済みのDBとは別の情報なので、SQLiteバックアップには未登録の下書きは含まれません。

## 技術スタック

- **フレームワーク**: [Next.js](https://nextjs.org/) (App Router, Static Export)
- **UI**: React, styled-jsx
- **デスクトップ**: [Tauri v2](https://v2.tauri.app/)
- **DB**: SQLite ([`@tauri-apps/plugin-sql`](https://v2.tauri.app/plugin/sql/))
- **言語**: JavaScript
- **テスト**: Vitest

## セットアップ

### 前提条件

- [Node.js](https://nodejs.org/) (v20以上推奨)
- [Rust](https://www.rust-lang.org/tools/install)
- Tauri v2 の前提条件 ([公式ガイド](https://v2.tauri.app/start/prerequisites/))

### インストール

```bash
git clone https://github.com/okakanatto/Yarukoto.git
cd Yarukoto
npm install
```

### 開発

```bash
npm run tauri dev
```

> **注意**: `npm run dev` だけではTauri IPCにアクセスできないため動作しません。必ず `npm run tauri dev` を使用してください。

### ビルド

```bash
npm run tauri build
```

インストーラー (.exe) とポータブル版が `src-tauri/target/release/` 以下に生成されます。

### テスト

```bash
npm test
```

## ダウンロード

ビルド済みバイナリは [Releases](https://github.com/okakanatto/Yarukoto/releases) からダウンロードできます。

- **インストーラー版** (.exe): Windows用のセットアップファイル
- **ポータブル版** (.exe): インストール不要の単体実行ファイル
